# Nachtfragment – Artist Activity auf Joomla-Künstlerseiten\n\n## Funktion\n- Erkennt ausschließlich URLs im Muster `/index.php/artists/<slug>`.\n- Lädt `data/artist-activity.json` aus GitHub Pages.\n- Zeigt passende zukünftige Termine direkt unter der Künstlerüberschrift.\n- Verwendet nur veröffentlichte Einträge mit Status `confirmed`, `date_confirmed`, `lineup_announced` oder `date_confirmed_lineup_pending`.\n- Ungeprüfte Kandidaten aus `data/concert_candidates.json` werden nicht angezeigt.\n- Bestehende Konzert-Recherche-Workflows werden nicht verändert.\n\n## Joomla-Modul anlegen\n1. Im Joomla-Backend **Inhalt → Site-Module** öffnen (Menübezeichnung kann je nach Version leicht abweichen).\n2. Ein Modul vom Typ **Eigenes Modul / Custom** anlegen.\n3. Titel: `Nachtfragment Artist Activity`.\n4. Menüzuweisung: **Auf allen Seiten**. Das Script bleibt auf Nicht-Künstlerseiten unsichtbar.\n5. Im Editor auf HTML-/Quelltextansicht wechseln und Folgendes einfügen:\n\n```html\n<div id="nachtfragment-artist-activity"></div>\n<script src="https://niehustorsten-del.github.io/nachtfragment-events/artist-activity.js" defer></script>\n```\n\n6. **Vorbereitung von Inhalten / Prepare Content: Nein** einstellen.\n7. Modul speichern und veröffentlichen.\n\nWenn Joomla oder der Editor das Script-Element beim Speichern entfernt, das Script nicht immer wieder in den Editor einfügen. Dann das Script über die Template-Funktion für benutzerdefinierten Code bzw. ein Custom-Code-Modul einbinden und den Platzhalter im Modul belassen. Keine Zugangsdaten oder FTP-Passwörter weitergeben.\n\n## Prüfen\n- `https://nachtfragment.de/index.php/artists/selofan`\n- `https://nachtfragment.de/index.php/artists/jahrund`\n\nDer Block erscheint unter der Künstlerüberschrift. Auf anderen Seiten wird nichts angezeigt.\n\n## Aktualisierung\nDer GitHub-Workflow **Nachtfragment Artist Activity Feed** läuft mittwochs und sonntags um 06:45 UTC. Er kann unter **Actions → Nachtfragment Artist Activity Feed → Run workflow** manuell gestartet werden.\n\nDer Feed baut auf den veröffentlichten Einträgen in `concerts.json` auf. Neue Recherche-Kandidaten erscheinen erst, wenn sie geprüft und in den veröffentlichten Konzertbestand übernommen wurden.\n\n## Weitere Künstleraktivitäten\nDiese erste Stufe bindet die vorhandenen Konzertdaten ein. Neue Veröffentlichungen, Musikvideos, Interviews, Line-up-Änderungen und Tourankündigungen sollten als eigener, quellenbasierter News-Feed ergänzt werden. Bloße Suchtreffer werden nicht als Fakten ausgegeben.
