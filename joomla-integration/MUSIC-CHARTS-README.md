# Joomla-Integration: Nachtfragment Music Charts

1. Joomla-Beitrag oder Eigenes HTML-Modul für „Music Charts“ anlegen.
2. Den vollständigen Inhalt aus `music-charts.html` im HTML-/Quellcode-Modus einfügen.
3. Falls Joomla das Script entfernt, in einem Modul/Editor mit erlaubtem JavaScript einfügen.
4. Menüeintrag auf den Beitrag bzw. die Modulposition setzen.

Die Chartliste wird direkt aus `data/music-charts.json` des GitHub-Repositories geladen. Die bestehende GitHub-Automation bleibt unverändert. Das Snippet ist responsiv und CSS/JS sind auf `#nf-music-charts` begrenzt.
