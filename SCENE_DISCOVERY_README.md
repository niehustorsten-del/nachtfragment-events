# Nachtfragment Scene Discovery V4

V4 sucht ausschließlich permanente Szene-Orte: Clubs, Bars, Shops und echte Szene-Organisationen/Promoter.

Events, Festivals, Konzerte, Touren, Partys, Ticketseiten, Kalender und Aggregatoren werden hart verworfen. Alte Event-/Festival-Kandidaten werden beim nächsten Lauf aus `data/scene_candidates.json` entfernt.

Eine Stadt allein wird niemals geokodiert. Ein Kartenpunkt benötigt eine konkrete Adresse.
